# ตั้งค่าอีเวนต์จาก ThaiTicketMajor

1. เปิด `http://localhost:8090/admin` และเข้าสู่ระบบผู้ดูแลหากระบบร้องขอ
2. เพิ่มอีเวนต์ด้วยรหัส `kpop-masterz-2026` และชื่อที่ต้องการ หรือเลือกอีเวนต์เดิมจากรายการ
3. กด **Event Config** แล้ววางลิงก์หน้าอีเวนต์ในช่อง **ลิงก์ ThaiTicketMajor**
4. กด **วิเคราะห์และสรุปการตั้งค่า** ระบบแสดงข้อมูลที่พบ หลักฐาน ราคาอ้างอิง และค่าจำลองที่จะคงไว้
5. ถ้าหน้าเว็บตอบกลับ 403 หรืออ่านไม่ได้ ให้เปิดลิงก์ในเบราว์เซอร์ คัดลอกข้อความรายละเอียด แล้ววางใน **ถ้าอ่านลิงก์ไม่ได้: วางข้อความจากหน้าอีเวนต์** และวิเคราะห์อีกครั้ง
6. กด **นำข้อมูลที่พบมาใส่ในฟอร์ม** ตรวจสอบชื่อ สถานที่ วันแสดง และจำนวนบัตร
7. ตรวจสอบ **โซนและราคา (JSON)** ด้วยตนเอง ราคาที่ดึงได้ยังไม่ใช่การจับคู่ผังจริงกับโซนจำลอง ใช้รหัสโซนที่ระบบรองรับเท่านั้น: `VIP`, `RED`, `RED_RESTRICTED`, `BLUE`, `YELLOW`, `GREEN`, `TEAL`
8. เลือกสถานะขายและ Workflow ของแล็บ แล้วกด **บันทึก** ดูผลได้ที่ `/events`

สำหรับงาน K-POP MASTERZ:

```
https://www.thaiticketmajor.com/concert/2026-k-pop-masterz-special-live-in-bangkok-bambam-mark-jayb.html
```

เมื่ออ่านหน้าเว็บไม่ได้ ระบบมีข้อมูลอ้างอิงเดิมของงานนี้: ชื่อเต็ม, ธันเดอร์โดม สเตเดียม และวันแสดง 14 พฤศจิกายน 2569 โดยระบุชัดเจนว่าเป็นข้อมูลที่ตรวจสอบไว้เมื่อ 2 ตุลาคม 2569 ไม่ใช่ข้อมูลล่าสุด ส่วนราคา ผังโซน และจำนวนบัตรต้องตรวจสอบเพิ่มเติม

การวิเคราะห์ไม่บันทึกการตั้งค่าและไม่เปลี่ยนคิวอัตโนมัติ ระบบไม่ดึงหรือกำหนดเวลาเปิดขายจริง และไม่อนุมานระบบป้องกันจากหน้าอีเวนต์ Workflow เป็นค่าร่วมของทุกอีเวนต์ในแล็บ

Workflow Profile ในสรุปแสดงค่าที่จะใช้จริงตาม Profile ที่เลือก:

- **A**: เข้าคิวก่อน แล้ว Login ก่อนเลือกที่นั่ง
- **B**: Login ก่อนเข้าคิว
- **C**: สุ่ม CAPTCHA 25%
- **D**: Login ก่อนคิว/เลือกที่นั่ง/ล็อกที่นั่ง, สุ่ม CAPTCHA 50%, คิวตามคะแนน
- **custom**: ใช้ค่าที่กำหนดในช่อง Workflow

หากเปลี่ยน Profile หลังวิเคราะห์ ให้กดวิเคราะห์อีกครั้งเพื่ออัปเดตสรุป ก่อนกดบันทึกการตั้งค่า

รองรับรายละเอียดจาก JSON-LD Event, ชื่อจาก `og:title`, ข้อความสถานที่, ราคาบัตร, วันแสดงแบบ ISO หรือชื่อเดือนภาษาไทย และเงื่อนไขจำนวนบัตรที่ระบุชัดเจน ข้อมูลที่อยู่ในรูปภาพหรือรูปแบบอื่นอาจไม่ถูกอ่าน ระบบจะไม่แต่งข้อมูลที่ขาดหาย

หากใช้งานผ่าน Docker ให้ rebuild gateway หลังเปลี่ยนโค้ด:

```powershell
docker compose -f defense-bot/docker-compose.defense.yml up -d --build gateway
```
