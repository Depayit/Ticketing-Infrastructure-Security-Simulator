# Visual assets

- `concert-crowd.jpg` is a real concert photograph by [Thomas Lamars on Unsplash](https://unsplash.com/photos/concert-lights-illuminate-the-packed-stadium-crowd-sxE-aCP1DjQ), downloaded on 2026-09-30 and resized for the lab interface. It is used under the [Unsplash License](https://unsplash.com/license). The photo is general atmosphere artwork, not a poster or an image of the simulated event.
- `venue-map.svg` is an original illustrative seating diagram made for this repository. It does not represent an actual venue layout.

The interface does not use AI-generated imagery. The simulated event name, dates, zones, payments and queue behavior remain lab data.
