คู่มือการติดตั้งและการใช้งาน (Operation Guide)

ขั้นตอนการรันระบบผ่าน Docker, การตั้งค่าตัวแปรสภาพแวดล้อม (Environment Variables) และพอร์ตให้บริการ

1. ขั้นตอนการติดตั้งและเริ่มต้นระบบ (Quick Start with Docker)

สามารถเปิดใช้งานระบบจำลองความปลอดภัย (Defense Demo) ทั้งหมดได้ผ่าน Docker Compose ด้วยคำสั่งเพียงชุดเดียว: 

# 1. ย้ายเข้าโฟลเดอร์ defense-demo
cd defense-demo

# 2. เริ่มต้นรันบริการทั้งหมด (Edge WAF, Akamai, Queue-it, AI Fraud Engine, Seat, Payment)
docker compose -f docker-compose.defense.yml up --build

2. ตารางพอร์ตและ URL ให้บริการ (Service URLs & Endpoints)

URL Endpoint Target View / Service Active Defense Layers
http://localhost:8090/ Waiting Room (TTM UI) Edge + WAF + Akamai Sensor + Queue-it Priority Queue
http://localhost:8090/?demo=1 Demo Mode (~8s countdown) เปิดใช้งานทุกชั้นการป้องกันแบบเร่งเวลา
http://localhost:8090/seats ผังเลือกที่นั่ง (Seat Map) AI Behavioral Telemetry & IsolationForest ML Engine
http://localhost:8090/checkout หน้าชำระเงิน & OTP 3DS 3DS Payment Gateway (Mock OTP: 123456)
http://localhost:8090/admin Live Audit Dashboard สตรีมเหตุการณ์การบล็อกสดทุก Layer (IP/AI/3DS)
http://localhost:5173/ Offense Worker Dashboard ควบคุมสถานะ Workers และกระจายภารกิจยิงตั๋ว

3. รายการตัวแปรปรับแต่งสภาพแวดล้อม (Environment Configuration Variables)

Environment Variable Default Value Description & Functional Impact
BOT_CHALLENGE_THRESHOLD 55 คะแนน Bot Score ขั้นต่ำที่เริ่มบังคับส่ง Challenge Modal
BOT_SCORE_ADMIT_MAX 75 คะแนน Bot Score สูงสุดที่ไม่ยอมรับเข้าเลือกที่นั่ง (Deny Admission)
ADMISSION_RATE 50 อัตราปล่อยผู้ใช้จากห้องรอเข้าเลือกที่นั่งต่อช่วงเวลา Window
EDGE_DDOS_GLOBAL_RPS 800 จํานวน Request สูงสุดรวมทั้งระบบต่อวินาที (Global RPS Cap)
GRAPHQL_ENABLED false สวิตช์เปิด/ปิด /graphql/v2 เพื่อป้องกันบอทยิงตรงข้ามคิว
BOT_BYPASS_BLOCK true บล็อก API ที่ไม่มีเซสชัน Akamai Sensor สอดไส้มา
AI_LAYER_ENABLED true เปิด/ปิด การตรวจสอบพฤติกรรมเมาส์และสกอร์ลของ AI Fraud Engine
