ระบบการจำลองบอทและการโจมตี (Offensive Automation Engine)

โครงสร้างระบบบอทกดบัตรความเร็วสูง เทคนิคการหลบเลี่ยงการตรวจจับ (Stealth) พร็อกซีหมุนเวียน และการข้ามขั้นตอนระบบตั๋ว

ข้อระวังความปลอดภัย: โมดูลในฝั่ง Offense พัฒนาขึ้นมาเฉพาะเพื่อวัตถุประสงค์ในการวิจัยเชิงป้องกัน (Defensive Security Research) และการประเมินความทนทานของระบบตั๋ว ห้ามนำไปใช้ยิงระบบจริงที่ไม่ได้อนุญาต

โครงสร้างส่วนประมวลผลบอท (Worker Engine Anatomy - /worker)

bot.py (Execution Engine)

แกนหลักควบคุมรอบการทำงานของบอท รองรับการยิงแบบ Concurrent GraphQL HTTP requests และการควบคุม Playwright Browser ในระดับ headless/headful

stealth.py (Evasion Suite)

โมดูลปลอมแปลงรอยนิวสัมผัสเบราว์เซอร์ (Fingerprint Masking) หลบเลี่ยง Chrome DevTools Protocol (CDP) detection, navigator.webdriver, Canvas และ WebGL fingerprints

ai_recovery.py (Adaptive Recovery)

ระบบกู้คืนสถานะบอทอัตโนมัติเมื่อเจอต้านทาน (Rate Limit / Challenge) เช่น การสั่งสลับ IP พร็อกซี การเคลียร์ Cookies หรือการลดอัตรา Request

กลยุทธ์การกดบัตรของบอท (Attack Execution Strategies)

1. Token Warmup Loop (_token_warmup_loop)

บอทจะเริ่มต้นยิง Request เพื่อรับและอุ่น Token สิทธิ์การซื้อไว้ล่วงหน้าก่อนที่บัตรจะเปิดขายจริง เมื่อเวลาเปิดขายมาถึง บอทสามารถส่งคำสั่ง addToCart หรือ reserveSeat ได้ทันทีโดยไม่ต้องเสียเวลารอคิวเริ่มต้น 

# ตัวอย่าง Snippet การอุ่น Token ล่วงหน้าใน worker/bot.py
async def _token_warmup_loop(self):
    while self.running:
        token = await self.fetch_session_token()
        if token:
            self.token_pool.append(token)
        await asyncio.sleep(self.warmup_interval)

2. Purchase Wave Wave (_purchase_wave_custom)

เมื่อถึงเวลาเปิดขายตั๋ว (Target Timestamp) บอทจะเปิดการยิง Concurrent HTTP Wave พร้อมกันมากกว่า 50–200 คำสั่งต่อวินาที ผ่านพูลพร็อกซีหลาย IP เพื่อส่งคำสั่งล็อกที่นั่งให้สำเร็จก่อนมนุษย์ทั่วไป 

# ตัวอย่าง Snippet Concurrent Purchase Wave
tasks = [
    self.session.post(BUY_ENDPOINT, json={"seat_id": s, "token": t})
    for s, t in zip(seats, self.token_pool)
]
results = await asyncio.gather(*tasks, return_exceptions=True)

ระบบหมุนเวียน พร็อกซี และ Bot Connector

Proxy Rotator Engine (/proxy-rotator)

ระบบบริหารจัดการพูล IP Proxy (Residential & Datacenter Proxies) ทำหน้าที่ตรวจสอบความเร็ว (Healthcheck) และสลับ IP อัตโนมัติเมื่อ IP เดิมติด WAF Rate Limit หรือ Cloudflare/Akamai challenge

Bot Connector & Sandbox (/bot-connector)

ส่วนเชื่อมต่อ API ภายนอกสำหรับการรันบอทในสภาพแวดล้อม Sandbox ปิดกั้นการส่งผ่านข้อมูลที่ไม่ปลอดภัย พร้อมระบบจัดการ Authenticated Session Pools สำหรับการสร้างบัญชีผู้ใช้งานจำลองจำนวนมาก
