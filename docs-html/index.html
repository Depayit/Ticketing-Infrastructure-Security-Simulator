ภาพรวมระบบ (System Overview)

Ticketing Infrastructure Security Simulator — แพลตฟอร์มจำลองและศึกษาระบบความปลอดภัยของการจำหน่ายตั๋วสเกลใหญ่

วัตถุประสงค์การวิจัย: แพลตฟอร์มนี้พัฒนาขึ้นเพื่อศึกษา พัฒนา และทดสอบกลไกป้องกันทางไซเบอร์ (Cyber Defense) ร่วมกับการวิเคราะห์พฤติกรรมการโจมตีด้วยบอทอัตโนมัติ (Automated Scalper Bots) ในสภาพแวดล้อมจำลองแบบเปิด (Controlled Simulation Environment)
Offensive Automation Offense

จำลองการทำงานของบอทกดบัตรความเร็วสูง Multi-worker architecture, Stealth Browser Fingerprinting, Session Warmup, Proxy Rotation และ Token Pre-generation

Defensive Security Defense

จำลองโครงสร้างป้องกันหลายชั้น (Swiss Cheese Model) ได้แก่ WAF Rate Limiting, Akamai Bot Score/Sensor, Queue-it Waiting Room, AI Fraud Engine และ 3DS Payment Verification

Central Orchestration Manager

ส่วนการกระจายงานกลางผ่าน Redis Pub/Sub, การรวบรวม Telemetry แบบ Real-time, ระบบควบคุมผ่าน Telegram Bot และหน้าจอ Admin Audit Dashboard สด

แผนผังสถาปัตยกรรมระบบภาพรวม (High-Level Architecture)

คลังภาพถ่ายหน้าจอจริงของระบบ (Real System Screenshots)

ภาพถ่ายการทำงานจริงของระบบจำลองความปลอดภัย TTM Defense Demo และส่วนควบคุมการทำงาน:

1. หน้าล็อกอิน & Defense Layer 1

หน้าล็อกอินสมาชิกพร้อมการตรวจสอบ IP At Gateway (WAF Rate Limit)

2. Entry Zone Modal

หน้าต่างการแจ้งเตือนเปิดระบบห้องรอคอย ("YOU ARE NOW IN THE ENTRY ZONE")

3. Countdown Timer

ระบบนับถอยหลังก่อนเปิดขายตั๋วอัตโนมัติ (Waiting Room Countdown)

4. Akamai Priority Queue

หน้าจอแสดงผล Akamai Bot Score: 21/100 (Priority สูง สำหรับมนุษย์)

5. Akamai Challenge Modal

หน้าต่าง Interactive Drag Puzzle สำหรับยืนยันตัวตนเมื่อ Bot Score สูง

6. Challenge Error Alert

แจ้งเตือน "เรียงภาพผิด กรุณาต่อคิวใหม่" เมื่อแก้ Challenge ล้มเหลว

7. เลือกรอบการแสดง (Show Dates)

หน้าเลือกรอบคอนเสิร์ต (พฤหัสบดี 3 ธ.ค. / เสาร์ 5 ธ.ค. / อาทิตย์ 6 ธ.ค.)

8. Seat Selection Map

ผังเลือกโซนและจำนวนที่นั่งพร้อม Pessimistic Seat Locking

9. Checkout Step 1 Details

กรอกชื่อ-นามสกุลผู้เข้าชม และเลือกรับสิทธิพิเศษ UOB / T1

10. Payment Method Options

เลือกช่องทางชำระเงิน (บัตรเครดิต/เดบิต, มือถือ, WeChat/Alipay, Shopee, QR)

11. 3D Secure QR Gateway

หน้าต่างจำลองสแกนชำระเงิน QR Code แบบ 3D Secure Gateway

12. Payment Success Alert

แจ้งเตือน "การชำระเงินเสร็จสิ้น!" พร้อม Commit ที่นั่งเข้า DB สมบูรณ์

13. Defense Admin Live Audit

หน้าแอดมินสตรีมบล็อกเหตุการณ์สดและควบคุมสวิตช์ระบบป้องกัน

14. Stealth Bot Controller UI

หน้าจอควบคุมบอท Playwright Stealth, สลับโหมด และเริ่ม/หยุด Workers

15. Telegram Dashboard

หน้าต่างควบคุมระบบและตั้งค่าบอทแจ้งเตือนผ่าน Telegram

สรุปโมดูลย่อยภายในระบบ (System Modules Summary)

Module Directory Role & Responsibility Key Technologies
Manager 📂 /manager จัดลำดับงาน ควบคุม Workers, ส่งผ่านข้อมูล Telemetry และรองรับ Telegram Bot FastAPI, Redis, Telegram API
Worker Engine 📂 /worker ประมวลผลภารกิจกดบัตร, ปลอมแปลงเบราว์เซอร์ (Stealth), ทำ Session Warmup Python, Playwright, Stealth JS
Proxy Rotator 📂 /proxy-rotator จัดการ พูล พร็อกซี, สลับ IP อัตโนมัติ, กระจายทราฟฟิกป้องกัน IP Ban FastAPI, Proxy Pools
Bot Connector 📂 /bot-connector เชื่อมต่อระบบภายนอก Sandbox Execution และจัดการ Session Tokens Python, REST SDK
Defense Demo 📂 /defense-demo ระบบจำลองการป้องกันตั๋ว: Edge WAF, Akamai Bot Score, Queue-it, AI Fraud, 3DS FastAPI, Redis ZSET, IsolationForest
Frontend Dashboard 📂 /frontend หน้าต่างควบคุมระบบ ติดตามสถานะ Workers แบบ Real-time และดู Live Audit Logs React, TypeScript, Vite

Python 3.11+, FastAPI, Asyncio, Playwright Engine, WebSockets

State & Queue

Redis 7.0 (Sorted Sets for Priority Queue, Pub/Sub, Key-Value Locks)

AI & Analytics

Scikit-learn (IsolationForest), Behavioral Biometrics SDK, Telemetry Engine

Deployment

Docker, Docker Compose, Multi-Container Orchestration, Edge Proxy
